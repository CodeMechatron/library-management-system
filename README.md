# Library Management System

A desktop-based Library Management System built with Python and CustomTkinter.

This application provides a modern graphical interface for managing books, including adding, viewing, searching, borrowing, returning, updating, and deleting books.

## Features

- Add new books
- View all books
- Search books
- Borrow books
- Return books
- Update book information
- Delete books
- Track book availability
- Dashboard showing:
  - Total books
  - Available books
  - Borrowed books
- Search/filter books by:
  - Book ID
  - Title
  - Author
- Persistent data storage using JSON
- Modern dark-themed graphical interface

## Technologies Used

- Python
- CustomTkinter
- Tkinter
- JSON
- ttk Treeview
